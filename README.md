# Portfolio Home Prototype v2

This pass intentionally preserves the v1 spacing, masthead proportions, palette, and supporting-copy composition while pushing two areas harder:

1. **Display typography** — `BRIAN` moves to Climate Crisis and `HARVEY` moves to Monoton for a more psychedelic, poster-like identity treatment. Space Grotesk and Space Mono remain the functional workhorses.
2. **Geometry** — the simple orange/purple rectangles become an orthogonal composition with bordered planes, cutouts, rules, and controlled overlap. The intent is a blend of De Stijl discipline and restrained neobrutalist weight rather than generic decorative boxes.

The palette is unchanged so typography and geometry can be evaluated independently from color.

## Run locally

```bash
pnpm install
pnpm dev
```

The prototype remains light-theme-first. Semantic theme tokens are retained so dark-mode mappings can be introduced after the palette direction is approved.
